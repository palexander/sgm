# Optional Integrations

This folder stores optional integration approaches for SGM.

The examples here are intentionally separate from the core CLI so they can be
adopted, copied, or ignored independently. They are practical templates rather
than required runtime dependencies.

Current examples:

- `claude-hooks/` for Claude Code hook-based enforcement of the SGM workflow
- `codex-hooks/` for Codex hook-based enforcement of the SGM workflow
- `pre-commit/` for a model-agnostic final gate before commits
